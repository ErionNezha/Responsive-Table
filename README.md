# 📊 Tabela Responsive

Tabelë HTML me dizajn modern që përshtatet me çdo ekran: në desktop shfaqet si tabelë klasike, në telefon kolonat kthehen në karta të etiketuara (përmes atributit data-th).

## Si ta hapësh

Hap `index.html` në browser — tab-i **Live Demo** tregon demon funksionale, tab-i **Kodi Burim** tregon të gjithë kodin.

Ose hap direkt `demo/index.html` për demon.

## Struktura

- `index.html` — faqe showcase (Live Demo + Kodi Burim)
- `demo/` — demo/index.html, demo/style.css
- `original/` — burimi origjinal i paprekur
- `PROVENANCE_LICENSE.txt` — provenienca dhe licenca
